AIS-138 FORMULA CALCULATOR ⚡ EV CHARGING SYSTEM

Electric Vehicle Conductive Charging System

Calculations for AC control-pilot duty cycle and available current (Part 1), and DC fast charging body-contact and earth-leakage currents across an electrical safety insulation network (Part 2).

AC Charging — Duty Cycle (6A–51A range)

% Duty Cycle = Current[A] / 0.6  ·  Max Current Drawn = % Duty Cycle × 0.6
% Duty Cycle 16.667 %
Max current drawn by vehicle 10.000 A
Applies for available line current in the 6A–51A band, per the workbook.

AC Charging — Duty Cycle (51A–80A range)

% Duty Cycle = (Current[A] / 2.5) + 64  ·  Max Current Drawn = (% Duty Cycle − 64) × 2.5
% Duty Cycle 84.400 %
Max current drawn by vehicle 51.000 A
Applies for available line current in the 51A–80A band, per the workbook.

DC Charging — Body Current & Earth Leakage Current

Ih = Vdc × (R + Rf) / (R × Rf)  ·  Ig = Vdc / (R + 2 × Rf)
DC Body Current Ih 6.000 A
DC Earth Leakage Current Ig 0.800 A
Applies for DC conductive fast charging safety insulation resistance network, per AIS-138 Part 2.
